# Рядом — демоверсия сервиса обратной связи

Независимая концепция сайта для сбора обращений о посещении магазинов.

## Что есть в демоверсии
- Адаптивная главная страница.
- Форма обращения с выбором «Магнит», «Пятёрочка» или другой сети.
- Локальная генерация номера обращения и просмотр статуса.
- Демо-панель для изменения статусов.

## Важно
Это только фронтенд-прототип. Обращения сохраняются в `localStorage` текущего браузера и **не отправляются на сервер**, не передаются торговым сетям и не запускают реальные проверки. Панель модератора не защищена и нужна только для демонстрации.

Для реального запуска потребуются сервер/API, база данных, авторизация модераторов, защита от спама, политика конфиденциальности и законный/прозрачный процесс передачи обращений адресатам. Не собирайте персональные данные до настройки этих компонентов.

## Публикация через GitHub Pages
1. Откройте **Settings → Pages** в репозитории.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Выберите ветку **main** и папку **/(root)**, затем нажмите **Save**.
4. Дождитесь завершения публикации. GitHub покажет адрес сайта в этом же разделе.

Проект независимый и не связан с «Магнитом», «Пятёрочкой» или государственными органами.
